# Demo guide

`npm run web:demo` starts the web app in explicit demo mode: a yellow banner says so on every screen, data lives in this browser only, and there is no account or password.

1. Continue in demo mode.
2. Home shows profile completeness and the best-fitting open sample scholarships.
3. Discover: search, toggle "Hide scholarships that don't match my profile" and "Include closed scholarships".
4. Open a scholarship: see per-criterion eligibility, documents, and set your progress. Approved/rejected are never offered to students.
5. Saved, Applications, Alerts (deadlines within 14 days for saved items).
6. Profile: consent is required to save; change income or percentage and watch eligibility change.
7. Assistant: labelled demo assistant, keyword matching only.

All records are fictional samples, not real scholarships.
